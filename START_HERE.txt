手势控制 · 使用说明
========================================

一个用摄像头识别手势、直接操控电脑的小工具（纯 CPU 实时，不用显卡）。


一、三步开始
------------------------------
1) 把压缩包解压到任意目录（路径别带中文更保险，例如 D:\hand-control）

2) 首次使用：双击 setup.bat
   它会自动建虚拟环境并安装依赖（约 200 MB，需要联网，几分钟）

3) 双击 run.bat
   第一次建议双击后加参数试跑：在命令行里执行
       run.bat --test
   --test 只识别、不发送任何按键，先确认手势认得准不误伤系统

3b) 想要「桌宠版」：双击 run_pet.bat
   桌宠浮在桌面上，会跟着你的手掌跑，做手势时有台词、表情和动作（七帧立绘 + 10 个动作）；
   手势规则完全一样。
   右键托盘图标可以：开关手势 / 鼠标穿透 / 换跟随方式 / 改手势映射 / 退出。
   没有摄像头也想先看看效果：run_pet.bat --demo
   注意：桌宠版需要额外装 PySide6 + PyYAML（setup.bat 会一起装好）。


二、电脑要求
------------------------------
· Windows 10 / 11，64 位
· 摄像头（笔记本自带即可）
· Python 3.11 - 3.13
  https://www.python.org/downloads/
  安装时务必勾选 "Add python.exe to PATH"
  （3.14 暂无 mediapipe 的安装包，装不上就退回 3.13）


三、常用手势
------------------------------
单手 = 操作窗口（要悬停 0.5 秒才触发，手要稳住不动；HUD 会显示进度条）
    张开手掌        最大化 / 还原
    握拳            最小化
    剪刀手          切换窗口
    食指            左手贴左半屏 / 右手贴右半屏
    点赞            窗口置顶 / 取消置顶
    踩              收起所有窗口（再比一次就回来）
    捏合            摸桌宠（不动系统）

  想玩桌宠？两条路都留着，一键切换：
  右键桌宠 -> 手势对照表 -> 顶部点「逗桌宠」，整套换过去（✌️跳舞 / ✊睡觉 /
  ✋唤醒 / ☝️跟随鼠标 / 👍开浏览器）。点「操作窗口」就切回来。
  也可以只改某一条：在下面 14 个下拉框里单独选。

双手 = 音乐（两只手要做同一个手势，左右不一样不会触发）
    都张开          播放 / 暂停
    都握拳          静音
    都点赞 / 都踩   音量 + / 音量 -
    都剪刀手        下一首
    都食指          上一首
    同时捏合保持 1 秒   开启 / 关闭全部控制（总开关）

关掉手势识别（不用比手势）
    · 点桌宠右上角的 ×        -> 关闭（摄像头也会释放，按钮变绿色 ▶，再点开回来）
    · 点一下桌宠              -> 身侧弹出三个圆按钮（鼠标停上去才显示名字）
                                  ⚙ 设置 -> 打开控制面板（开关 / 穿透 / 跟随 / 退出）
                                  🎮 互动 -> 单手手势整套切成"逗桌宠"
                                  🖥 操作 -> 单手手势整套切成"操作窗口"
    · 右键托盘图标            -> 同样的菜单（开了点击穿透之后只能走这里）

让它贴着窗口站（一眼看出手势在操作哪个窗口）
    · 点桌宠 -> ⚙ 设置 -> 跟随方式选「吸附」，或右键托盘 -> 吸附到窗口
    · 它就贴在当前前台窗口的右缘（放不下自动翻左），头顶显示窗口标题
    · 站位时是正面朝前的，不会侧着身子
    · 窗口最小化 / 最大化 / 全屏时不贴，回角落待命；窗口恢复自动贴回来
    · 命令行等价写法: run_pet.bat --follow window

让它跟着鼠标走（跟在指针后面，不挡点击）
    · 点桌宠 -> ⚙ 设置 -> 跟随方式选「跟鼠标」
    · 它会吊在指针后面 110px，追到就停，不会压在鼠标上
    · 指针不在它身上时，窗口是"鼠标穿透"的，点下面的按钮完全不受影响
    · 想点它出圆按钮：把鼠标挪到它身上停一下（0.12 秒），再点就行
    · 命令行等价写法: run_pet.bat --follow cursor

改手势（不用改代码）
    · 点桌宠 -> ⚙ 设置 -> 手势对照表，或右键托盘 -> 手势对照表（可修改）
    · 单手一页（7 个手势 × 左手/右手），双手一页（6 个手势）
    · 每行一个下拉框，选完点「保存」立刻生效；「不绑定」= 这个手势什么都不做
    · 选「恢复默认」一键回到出厂设置

摸它 / 看它演（这就是"互动感"的来源）
    · 点桌宠一下            缩一下、飘爱心："嘿嘿…好痒"
    · 连点 2~4 下           开心蹦一下："还要～"
    · 连点 5 下以上         鼓脸摇头："别、别再戳啦！"（停一会儿就消气）
    · 手势成功              蹦一下；失败会摇头并说出原因（"这个窗口不能最大化吧"）
    · 手离开 10 秒          打哈欠；40 秒 坐下；再久一点伸个懒腰
    · 手一回到画面          立刻站起来，离开超过 6 秒还会招手说"手来啦～"
    · 拖动它                会"吓一跳"（猛地一弹）
    · 它会换 7 张立绘：站 / 笑 / 招手 / 思考 / 瞌睡 / 生气 / 坐
    · 想换形象/换自己的画，见 pet/assets/NOTICE.md（丢一组同名 PNG 就行）

看它的动作表（不用摄像头）
    · run_pet.bat --snapshot-actions 动作表.png
      10 个动作各抽 5 帧并排，改动作时靠这张图验收


四、常见问题
------------------------------
Q: setup.bat 提示 "Python not found"
A: 没装 Python，或装的时候没勾 "Add python.exe to PATH"。装完重开一个窗口再试。

Q: 依赖装到 mediapipe 时失败
A: 国内网络问题。mediapipe 在清华镜像上没有，只能用官方源。
   挂了代理的话先设置再重跑：
       set HTTPS_PROXY=http://127.0.0.1:7890
       setup.bat

Q: 提示 "camera open failed" / 读帧失败
A: 摄像头被别的程序占着（微信、腾讯会议、QQ 视频等），关掉再试。

Q: 手势总是不触发
A: 三个原因按顺序排查
   1) 手要相对画面稳住——在动的时候计时是冻结的，HUD 会显示"手在动"
   2) 距离/光线：手要在画面里、大小适中，太暗识别会飘
   3) 跑 run.bat --trace，退出时会打印"为什么没触发"的统计

Q: 握拳老是被识别成点赞
A: 你的握拳姿势里拇指伸在外面了。握拳时把拇指收进拳内/夹在食指侧面。

Q: 嫌太灵敏 / 太迟钝
A: 见下面的参数，直接加在 run.bat 后面即可

       run.bat --hold 1.0            悬停更久才触发（默认 0.5 秒）
       run.bat --still-speed 0.35    手稍微动就不算数（默认 0.6）
       run.bat --pair-hold 0.6       双手音乐要举更久才触发（默认 0.4 秒）
       run.bat --toggle-hold 1.5     总开关要捏合更久（默认 1.0 秒）
       run.bat --debug               显示五指状态、捏合比、模型判定，校准用


五、目录结构
------------------------------
    setup.bat        首次安装（建 .venv + 装依赖）
    run.bat          启动（命令行 HUD 版）
    run_pet.bat      启动（桌宠版）
    main.py          主程序（HUD 版）
    pet/             桌宠版（分层结构，说明见 ARCHITECTURE.md）
    pet/assets/      桌宠立绘（girl/ 是现在的七帧；whale_* 是上一版，可切回）
    tools/           prep_sprites.py：把自己的图抠成透明立绘的小工具
    camera.py        摄像头打开（两个版本共用）
    gestures.py      手势判定、防抖等判定原语
    hand_tracker.py  手部关键点 + 官方手势分类模型
    actions.py       按键/滚轮/窗口操作等系统动作
    face_guard.py    人脸否决（防止把脸当成手）
    calibrate.py     手势自测工具（动作之间带 1 秒休息）
    tests/           单元测试（不需要摄像头）
    models/          模型文件，约 17 MB，别删

六、退出
------------------------------
· HUD 版：窗口里按 q 或 Esc
· HUD 版：运行时按 a 可临时开关手势控制
· 桌宠版：点桌宠右上角的 × 关手势识别（桌宠还在，再点 ▶ 恢复）
· 桌宠版：要完全退出 -> 点桌宠 → ⚙ 设置 → 退出程序，或右键托盘 → 退出
· HUD 变红显示"已停止"表示控制已断开
